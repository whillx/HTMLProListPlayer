    Keys

    → PageDownNext clip. If the first clip is ready (waiting on its first frame), starts it. During a Trans clip, skips the rest of it. While paused, shows the next clip on its first frame and stays paused.
    ← PageUpPrevious clip, skipping Trans clips; while paused, stays paused. On the first clip (or when only Trans clips come before it): back to the first frame of the first clip, ready for →.
    Space or the play / pause buttonPause or resume.
    Back-to-start buttonFirst clip, first frame, paused.
    Previous / next buttonsLike ← / →, but they never start the first clip when it is ready: they move to the next clip instead.
    Seek barMoves within the current clip; playing stays playing, paused stays paused. The first clip, paused and moved back to its first frame, is ready again: → starts it.
    < / >Back / forward 3 seconds in the current clip, like the seek bar. Stops at the first or last frame of the clip.
    Volume slider / speaker iconSets the volume / mutes and unmutes (remembered).
    F, fullscreen button, or double-click videoToggle fullscreen.
    EscExit fullscreen.

    What happens at the end of a clip

    Loop (default)Repeats until you press →.
    OncePlays once and holds the last frame.
    TransMoves on to the next clip by itself.

    Presentation clickers usually send PageDown / PageUp, so they work too. Drag a thumbnail to reorder the playlist. Tick the boxes on the left to edit several clips at once: changing the status or deleting one selected clip applies to all selected clips (reordering is off while more than one is selected). In fullscreen, the playback buttons appear when the mouse is over the bottom of the screen.

    Import playlist?

    ProList Player 3.0

    A simple player for local presentation videos. The playlist is saved in this browser automatically; use Playlist → Export… to save it as playlist.js. Playlists store only file names. Put playlist.js next to this HTML file and the player offers to import it whenever its playlist is empty.

    When a playlist loads, each video is looked for in the player's folder and the subfolders right below it (the first file with that name wins). Videos that aren't there can be found with Locate folder… or Locate files…; those stay available until the page is closed.

    Keep the css/ and js/ folders next to this HTML file.
